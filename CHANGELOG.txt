[b]Build Smarter, Rebuild Faster - Catalogue Visibility & Multiplayer Reliability Update[/b]

[list]
[*][b]Multi-category browsing:[/b] Categories can now be combined with Shift-click, making it possible to browse related sets together, for example walls, doors and windows, while filters automatically include the combined selection.
[*][b]Larger icons and focused previews:[/b] Added Default, Large and Extra Large buildable-icon sizes for both the normal catalogue and Compact mode. Added optional hover previews beneath each favorite star, so previews appear only when deliberately requested. Compact previews include descriptions, capacities, materials, tools and skill requirements; normal and detailed-list previews show only the enlarged buildable. Hover previews are disabled by default and have their own size setting.
[*][b]Improved gathering and build queues:[/b] Gather zones now recognize loose items placed directly on the ground as well as items inside crates, bags, nearby containers and vehicles. Pinned requirement totals include those world items, and queued plans can walk to and collect them automatically.
[*][b]Multiplayer definition validation:[/b] Added a safe retry for the B42.20 client/server definition handshake, preventing a dropped initial response from leaving players permanently stuck on "Waiting for server definition validation."
[*][b]Pinned overlay controls:[/b] Added an unpin control to every pinned recipe and blueprint header, so obsolete entries can be removed directly from the overlay. Deleted blueprints are also detected and cleared automatically.
[*][b]Furnace and charcoal-burner placement:[/b] Blast, primitive and smelting furnaces, together with all charcoal-burner variants, now follow the base game's outdoor-only restriction. The restriction is validated by the definition schema, displayed in compact information and produces a clear placement reason indoors.
[*][b]Classic brick structures:[/b] Restored the Classic Brick Wall to catalogue searches and grouped it after Brick Wall (Poor), with its old and weathered appearance available through the finish selector. Poor brick walls, door frames and window frames no longer incorrectly offer plaster, paint or wallpaper finishes.
[*][b]Cleaner logging:[/b] Routine Knox Buildworks debug and information output is now disabled during normal play. Full diagnostics remain available through the Debug option, while genuine errors continue to be logged.
[*][b]Wall replacement:[/b] Finished player-built walls can now be replaced directly by another solid wall on the same edge. Door and window frames, openings, fences and map-authored walls remain protected, so changing a wall style no longer requires destroying and rebuilding its frame.
[*][b]Passable pillars and posts:[/b] Fixed the directional invisible collision created by wall pillars, tall posts and other explicitly passable decorative pieces. They now use collision-free world objects and remain walkable in every rotation, including sprites that are not registered as movable furniture.
[*][b]Magazine or skill progression:[/b] Learned construction recipes can now accept a skill threshold as an alternative to finding their magazine. Native B42 AutoLearn rules are preserved, required construction skills are used where available, and Metal Floor can be unlocked at Welding 1. Recipe-or-skill conditions are shown throughout the catalogue, detailed information, pinned recipes and requirement drawers.
[*][b]Metal rain drum:[/b] Added the four-direction base-game Metal Drum as a functional rainwater collector in Vanilla Expanded. It uses the native fluid-container system for multiplayer-safe water storage.
[*][b]Vanilla-style menu controls:[/b] Escape now closes the Knox Buildworks catalogue and its standalone guide, appearance, pinned-recipe, blueprint and administration windows, matching the base-game building and crafting menus.
[*][b]Localization formatting:[/b] Corrected parameterized translations to use numbered placeholders and direct getText arguments. Removed the blueprint UI's fallback-based safeText wrappers so translated strings now follow the base-game localization path consistently. This is due to B42.20.2 update.
[*][b]Two-sided frame construction:[/b] Walls can now be completed from a matching frame while the player stands on either usable face or the adjacent approach tile, instead of being routed through or around the frame to its anchor square. This also applies when building walls from plans and queues.
[*][b]Upper-storey perimeter walls:[/b] Walls, wall frames, door frames and window frames can now use a floor on either side of their placement edge, so south and east exterior walls no longer require a temporary floor outside the building.
[/list]


[b]Knox Buildworks - Build Rules & Appliances Update[/b]

[list]
[*][b]Build 42.20 multiplayer XP:[/b] Fixed XP awards for entity-backed buildables. Knox Buildworks now verifies the native CraftRecipe award, applies a safe fallback when Build 42.20 skips it, avoids duplicate XP and displays the normal crafting XP halo above the player.
[*][b]New server-authoritative Build Rules Editor:[/b] Added a new administration UI to the ElyonLib dock. Admins can enable, disable or inherit rules by category, subcategory and individual buildable, then customize each build stage's materials, tools, accepted items or tags, item-use behavior, skills, XP, learned recipes and construction time. Rules are validated, revision-checked, stored by the server and synchronized to every client, with the catalogue, pinned recipes, planning tools and construction all respecting the active settings.
[*][b]Rule presets and sharing:[/b] Added Current Server Rules, Definition Defaults and Disable All starting points, plus named client-side preset import and export. Presets can be backed up, shared and moved between servers without changing a server until an admin validates and saves them.
[*][b]Wall-finish policies:[/b] Added a Finishes tab where admins can make plaster, paint or wallpaper requirements free for all walls, then set individual walls to inherit, require or waive each cost. Non-wall paintable objects, including military crates, retain their normal paint requirements.
[*][b]Admin UI and performance:[/b] Reworked the preset area for clearer navigation and virtualized large scrolling lists to greatly improve performance in the Rules Editor, Test Runner and Tile Browser. Added distinct ElyonLib dock icons for all three tools.
[*][b]New in-game guide:[/b] Added a Survival Guide-style Knox Buildworks manual, opened from new information buttons. It covers the catalogue, variants, requirements, building, painting, functional objects, pinned recipes, planning, queues, sharing, accessibility, multiplayer troubleshooting and the complete admin workflow.
[*][b]Accessibility option:[/b] Added a toggle to Knox UI Appearance that prevents unavailable buildable icons from fading. Readiness indicators and building restrictions remain unchanged.
[*][b]Localization overhaul:[/b] Added full Spanish and Russian localization to both Knox Buildworks and Vanilla Expanded, completed and synchronized the English, Simplified Chinese, Spanish and Russian key sets, removed stray translations and centralized shared category and subcategory names in the main mod for add-on reuse.
[*][b]New functional appliances and bathroom fixtures:[/b] Added 36 buildables to Vanilla Expanded, including ovens, a wood stove, charcoal and propane BBQs, refrigerators and freezers, washing machines and dryers, toilets, a shower, a bathtub and several sinks. Matching styles are grouped for easier browsing, recipes use balanced welding, electrical and plumbing requirements.
[*][b]General and buildable fixes:[/b] Improved editor validation and error feedback, corrected the Large White Window name, allowed it to be installed in compatible passable interior arches without turning those walls into window frames, removed the obsolete tile-property patches, and tightened catalogue, pinned-recipe, planning and placement behavior around live rule changes.
[*][b]Buildables definitions:[/b] Removed the glass panels from the definitions of some window frames.
[/list]


[b]Previous Update - UI, Accessibility & B42.20 Compatibility[/b]

[list]
[*][b]Responsive catalogue:[/b] Reworked the layout for large fonts, smaller windows and different resolutions. The catalogue now opens at a more practical size and remembers the dimensions of each display mode.
[*][b]Compact mode:[/b] Added a condensed icon grid, B41 Building Menu inspired subcategory navigation, grouped-buildable carousel and full material/finish options.
[*][b]Layout fixes:[/b] Fixed blocked resize handles after switching modes, incorrect scrollbar sizing, clipped or overflowing text, overlapping controls and large-font issues in the catalogue and Planning Mode.

[*][b]Detailed-list performance:[/b] Greatly reduced freezing when opening the detailed list, selecting buildables or resizing the window. Detailed rows now respect the selected preview background and wrap long text correctly.

[*][b]Military crates:[/b] Added green, gray and white military crates with 100 storage capacity. Every variant can be painted using the white directional base sprites and the game's native custom-colour system.

[*][b]B42.20 file compatibility:[/b] Blueprint saves and exports now use JSON-formatted .txt files. Existing .json blueprints remain readable and are migrated automatically, while buildable definition files remain in JSON format.
