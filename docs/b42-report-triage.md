# B42 player reports — September–October 2026

This is an unreleased working-tree patch. The reports and screenshots are evidence, not implementation instructions. No live saves, server configuration, or Workshop upload were changed.

## Player / server notes

- For normal use, enable **ElyonLib**, **KnoxBuildworks**, and optionally **KnoxBuildworksVanillaExpanded** (those are the exact mod IDs). Clients and server need matching files; a Workshop subscription ID alone does not enable the mod/dependency IDs.
- Back up the complete save and server configuration while the server is stopped. Test adding/updating on a copy first. No automatic save conversion or dictionary cleanup is included here.
- For uninstall trouble, stop the server and retain its logs; restore the original mods and versions, or restore a complete pre-installation backup. Removing `WorldDictionary` files can destroy the ID mapping needed by saved objects. This patch does **not** make removing Knox mid-save safe.
- To build without preplanning, disable **Enable Planning Mode**. To keep vanilla's own menu available, leave **Replace Build Menu** off. F7 is the default Knox shortcut; change it under the game's Knox mod options.
- An old malformed rug is not repaired by rotating it in place. Test pickup of individual halves on a backup. If they remain orphaned, an admin must inspect/remove those exact objects; no sweeping cleanup is included.
